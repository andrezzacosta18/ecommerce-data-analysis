# E-commerce Sales Analysis

## Project Overview

This project simulates a real-world Data Analyst workflow using sales data from an e-commerce company.

The main goal is to apply different data analysis tools throughout the complete analytical process, from database creation and data exploration to visualization, dashboard development, and business insights.

The project integrates:

- SQL Server
- Excel
- Python
- Matplotlib
- Power BI

---

## Business Scenario

An e-commerce company wants to better understand its sales performance.

Management has noticed changes in sales results over time and wants to use data to determine whether the company is improving or declining and identify the factors influencing its performance.

---

## Business Problem

**How are the company's sales performing, and what factors are influencing the results?**

---

## Project Objectives

The project aims to:

- Design a relational database for e-commerce sales data.
- Create and manage the database using SQL Server.
- Analyze sales data using SQL.
- Explore and analyze data using Excel.
- Perform data analysis using Python.
- Create data visualizations with Matplotlib.
- Build an interactive dashboard using Power BI.
- Identify relevant business insights.
- Provide data-driven recommendations.

---

Used for database creation, data modeling, data storage, and analysis.

- Primary Keys
- Foreign Keys
- Constraints
- `INSERT`
- `SELECT`
- `WHERE`
- `ORDER BY`
- Aggregate Functions
- `JOIN`
- `GROUP BY`
- `HAVING`

### Excel

Used for data exploration, calculations, summaries, PivotTables, charts, and dashboard creation.

### Python

Used for data manipulation, exploratory data analysis, and further investigation of sales performance.

### Matplotlib

Used to create visualizations that support the analytical process and communicate findings.

### Power BI

Used to create the final data model, KPIs, interactive visualizations, and business dashboard.
